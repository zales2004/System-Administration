## Day 01 — Windows IT Support & Troubleshooting

Start here: [Day 01 study notes](Day-01-Windows-IT-Support/README.md)

The Day 01 module includes:
- Windows architecture and filesystem fundamentals
- Local users, groups, and least-privilege administration
- Processes, Task Manager, and Windows services
- Disk and system-file troubleshooting
- Network troubleshooting commands
- PowerShell administration and filtering
- Event Viewer and important Windows event IDs
- Practical labs, troubleshooting workflow, and interview revision
- Redacted screenshots from the completed PowerShell exercises

## Lab safety

- Use a dedicated test account and non-production environment for administrative exercises.
- Do not grant administrator rights unless the task requires them.
- Avoid stopping unfamiliar Windows services or terminating unknown processes.
- Back up important data before disk, partition, or system-repair operations.
- Screenshots in this repository have been reviewed to avoid exposing the registered-owner email address.

## Documentation approach

Each module separates concepts, commands, practical procedures, expected observations, troubleshooting guidance, and interview questions. Commands should be tested in an appropriate lab before use on production systems.
